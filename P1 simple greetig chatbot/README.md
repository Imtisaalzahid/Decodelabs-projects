# Rule-Based AI Chatbot 🤖

A simple, interactive Rule-Based AI Chatbot built in **Python** matching the exact requirements shown in the project specification image.

## 📋 Key Requirements Implemented
1. **Greetings & Exit Commands**: Recognizes greetings (`hello`, `hi`, `hey`) and exit commands (`bye`, `exit`, `quit`).
2. **If-Else Decision Logic**: Built using structured control flow and decision-making logic.
3. **Continuous Loop**: Runs continuously until an exit command is executed.
4. **GUI Interface**: Built with Python Tkinter for a sleek, modern desktop chat interface.

---

## 🚀 How to Run

### 1. Python GUI Chatbot (Recommended)
Launch the standalone desktop GUI window:
```bash
python chatbot_gui.py
```

### 2. Python CLI Chatbot (Console Version)
Run the continuous terminal loop version:
```bash
python chatbot_cli.py
```

### 3. Web GUI Version (Optional Browser Interface)
Open `index.html` in any web browser to experience the Web GUI version with dark mode, interactive prompt chips, and animation effects.

---

## 🛠️ Key Skills Covered
- **Control Flow**: `if`, `elif`, `else` conditional blocks.
- **Decision-Making Logic**: String keyword matching & command evaluation.
- **Looping Mechanism**: Continuous execution until termination signal.
- **GUI Development**: Event handling, state management, and UI styling in Python Tkinter.
